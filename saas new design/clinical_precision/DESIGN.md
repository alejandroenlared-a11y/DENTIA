# DENTIA DESIGN SYSTEM — ESPECIFICACIÓN PARA STITCH

## 1. PERSONALIDAD VISUAL
- **Atributos:** Sobrio, minimalista, serio, directo, compacto, muy ordenado.
- **Estilo:** Software clínico profesional, no plantilla SaaS genérica.
- **Formas:** Bordes finos, radio de 4-6px, sin sombras fuertes, sin gradientes.

## 2. PALETA DE COLORES
- **Fondo principal:** #F5F6F7
- **Superficie principal:** #FFFFFF
- **Superficie secundaria:** #F0F2F4
- **Borde principal:** #D9DEE3
- **Borde suave:** #E8EBEE
- **Texto principal:** #17212B
- **Texto secundario:** #5C6873
- **Acción principal:** #005A8C (Azul Sanitario)
- **Éxito:** #278561 (Verde sobrio)
- **Aviso:** #B37D00 (Ámbar oscuro)
- **Error:** #C53030 (Rojo clínico)

## 3. TIPOGRAFÍA (Inter / Sans Serif)
- **Título principal:** 20–22 px | Semibold (600)
- **Títulos de panel:** 14–16 px | Semibold (600)
- **Texto operativo:** 11–12 px | Regular (400) / Medium (500)
- **Etiquetas y Tablas:** 10 px | Medium (500)

## 4. COMPONENTES Y ESPACIADO
- **Radio general:** 4–6 px
- **Botón compacto:** 30–32 px altura
- **Fila de tabla:** 32–38 px altura
- **Padding base:** 12–16 px
- **Iconos:** 2D, lineales, minimalistas (Lucide style).

## 5. NAVEGACIÓN
- **Barra lateral:** 224 px (expandida) / 64 px (contraída).
- **Cabecera:** 52 px altura.
